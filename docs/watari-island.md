# 渡りの島：実装前技術設計（2026-11-06）

制作者の本依頼を採用元とする高リスク変更。基準mainは dfa8433。開いているPRはなし。D020、PR #37を確認。戦闘・保存・クエストは対象外。

## 配置と探索

開始 (8,30)、7.5mグリッドの東岸 (30.5,15) から東へ実橋で (113,15) に接続する。元の鳥居・北向きの主経路は維持。新島は概ね x96〜272、z−128〜64（176×192m以内）、既存広域地形と重ならない海域。輪郭は入り江を含む複数の曲線で作り、正方形の地域区画は作らない。

白亜岸(113,15)から樹海(143,−22.5)、赤土谷(158,−75)、星見(210.5,−90)、断崖(248,−60)、神殿(233,0)、図書庭園(203,30)、運河(158,30)を周回。高原花道(195.5,−22.5)へ横断の近道。枝道は北の採石場・観測台・灯台下・岸の古桟橋へ。各頂点は既存グリッドの中心に一致。大塔・灯台は複数の進路と橋から再発見する共通の目印。

## 地形・橋・衝突

新規の純粋データモジュールにルート・橋の範囲・島の高さをまとめる。既存地形の式・キャッシュ・世界境界は保持し、独立海域へ加算。新島は2m詳細メッシュ、中心平坦部と中央60%の緩斜面を使用。接続境界は既存8mメッシュと一致させる。描画と歩行は同じ三角形高さを使用。

橋の床は高さ関数の支持面として扱い、海底から土手を盛る描画にはしない。桁・欄干・橋脚・板または敷石は別メッシュ。欄干に連続した実衝突を置き、歩ける幅を確保する。柱は歩道外、入口は海岸へ重ねて段差を解消。自由移動でも同じ橋を往復できる。移動コアと入力数値は変更しない。

## 景観・音・空

9地域は白石の港、巨木の森、赤い採石谷、花と風車の高原、水門の運河、崩れた書架回廊、夕景の神殿、水鏡と観測台、灯台の崖。共通の古石・水路を連ね、尾根・林・廃墟が視界を分節する。オブジェクトは道から離し、セル中心・寸法に対応した衝突を持たせる。地域ごとの小バッチを既存カリングに接続し、独立乱数で既存物の位置を保つ。

既存Web Audioに9つの独立した新作を追加。新島では輪郭を持つ地域領域で判定し、単純な最近傍だけで決めない。0.7秒の定着待ち、境界のヒステリシス、1.6秒クロスフェードを維持。既存島へ戻ると既存の空・霧・曲へ復帰。既存空シェーダーを拡張して軽量な雲・星の地域表現を滑らかに補間する。

## 実装した地域・音楽・環境の台帳

`regions.js` の地域輪郭と `music.js` の楽曲データを対応させた。旋律は全曲別で、各ループは24〜56拍。音源・既存曲・外部CDNは使用せず、従来の発振器と、新しいリード・弦・ホルンの合成音を使う。拍数の異なる曲でも、旋律と和声が同じループ長に収まることを自動検査する。

### 密集した地域の切替

新島は中心点の最近傍では判定しない。運河岸・採石谷の縁・尾根に沿う多角形を台帳に持たせる。たとえば (165,−6) は樹海中心に近くても運河岸の領域であり、運河の曲と空を選ぶ。現在地域の輪郭から3m以内はその地域を保持し、次の地域に0.7秒定着してから曲と空の目標値を替える。新島で円形領域を重ねると細道の途中で曲が戻る問題を避けるための選択である。

橋の中ほど（x68以東、z15±5m）から渡り岸の環境へ入り、x68を戻ると既存の地域判定へ戻す。既存12地域の円形判定と15%の余裕は変更しない。`tests/regions.test.js` で全新地域の中心、輪郭の余裕、短い境界往復、全曲の完全なループと旋律差、既存全地域・浜への復帰を検査する。
