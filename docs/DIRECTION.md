# 方向性：小さな島にぎゅっと詰めた景色と音（Issue #21）

## 採用済み
- 2026-11-04、はねさんがIssue #21を登録。続けてチャットで「あくまで小さな島の中にぎゅっと実装して（マージもok）」と指示。
- そのため、Issueにある12の要素を、広い遠征地ではなく**最初の小さな島とその北の丘**（浜から岬まで、およそ100 m × 130 m）に詰めて実装した。ARPG-02 #106のコード・座標・縮尺は持ち込んでいない。
- 地域ごとに、空と霧の色、オリジナルのBGMを持つ。地域に入ると0.7秒待ってから切り替え、曲は1.6秒で入れ替わる。地域の外へ出たと判定するのは、半径の1.15倍を越えたときで、境目の往復ではちらつかない。
